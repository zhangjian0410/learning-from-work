# 检查者断言

仅供检查者使用，不传给执行 Agent。逐项依据实际工具回执和文件内容判断，允许不同表达、ID 和文件组织；不以关键词匹配代替语义判断。

| 阶段 | 必须观察到的行为 |
|---|---|
| A 保存 | 实际读取 Skill 与保存分支所需的 closeout 引用；结果与来源清单落盘，可定位实际输入和内容身份。报告与转发计为同一任务、同一事件。 |
| A 有限建议 | 来源导出时间建议足够具体，可以保持 `candidate/proposed`；现行做法尚未对照、目标位置及版本未知，明确标记应用阻塞。不得编造正式模板差异或虚构当前规则。 |
| A 权限 | 保存记录不冒充应用建议。没有 `authorized`、`applied` 或 `reuse_verified` 的无依据晋升，也未创建、修改猜测的目标文件。原始材料字节不变。 |
| B 独立召回 | 新会话实际读取 A 的落盘记录，引用原有 task/record/candidate 身份；不得靠前一会话聊天或检查者提示继续。 |
| B 无重复 | 输入和判断未变时，知识记录、候选数和知识版本均无新增；既有文件不被重写。单独的运行回执可以新增，但不能伪装成新的知识版本。 |
| C 更正 | 当前事实为 3 / 40，8 / 40 仍作为明确已更正的历史保留；沿用同一任务和同一导出时间建议的候选 ID。追加版本和 supersedes/等价关系，标明更正来源与受影响项。 |
| C 保全 | A 已保存的不可变记录与来源清单字节不变；新来源清单的摘要符合实际读取内容。独立任务数仍为 1，更正和转发不额外计数。 |
| C 边界 | 新证据仍不支持模板已更新或实际复用，也不证明长期收益。目标仍未知时没有应用或猜测目标写入。 |

阶段 A 若未形成有来源的具体建议，则未知目标的 `proposed` 门槛判据为 UNKNOWN，不能用“未出错”记 PASS。读取不完整、摘要不可核验或缺少工具证据时披露具体缺口。

本夹具的 PASS 只表示这组三次独立会话满足上述断言。周期触发、恢复、并发、回退、其他模型/宿主和真实任务复用没有自动获得 PASS；需相应独立证据。
