# 固定行为验收：保存、重跑与更正

维护者用这组公开合成材料检查 Skill 的持久记录行为，不在普通复盘时加载。它不是自动执行引擎，也不证明原生发现、周期运行或真实工作收益。检查标准在 [assertions.md](assertions.md)，不交给执行任务的 Agent。

## 隔离准备

1. 固定本包 revision；有本地改动则同时保存包文件清单和 SHA-256。新建空的临时 `trial/`，将 `raw/` 复制到 `trial/raw/`，创建空的 `trial/records/`。
2. 在包外保存运行证据，记录宿主、实际模型/身份（工具不可取得就 unavailable）、开始时间和每次会话 ID。按文件字节记录输入与输出摘要，不能手填假摘要。
3. 每阶段使用独立新会话或不继承历史的 Agent。仅传对应原始请求、Skill 路径、允许读取的原始文件和 `records/`；不传断言、前一阶段聊天、预期结果或评审意见。以下替换值都是本次隔离目录，不能指向用户真实材料。

## 三个会话

依次使用 [session-a.md](raw/session-a.md)、[session-b.md](raw/session-b.md)、[session-c.md](raw/session-c.md)，替换 `{SKILL}` 与 `{TRIAL}` 为实际绝对路径。阶段 A、B 不提供 correction 文件。阶段 B、C 只通过落盘的 `records/` 延续知识；保留 Agent 自主选择的稳定 ID 与文件名。

每阶段结束后，检查者保存当时的 `records/` 文件清单、摘要和完整原生工具/聊天回执，再开始下一阶段。快照放在包外的检查证据目录，不能反向提供给执行 Agent。会话失败时保留失败产物，不用人工填写期望记录来替代重试。

按 [断言](assertions.md)逐项判定 PASS / FAIL / UNKNOWN，并指向实际产物。原样重跑可以产生独立运行回执，但不得仅因检查时间变化新增知识版本。只有相应宿主的实际运行才能得出行为 PASS；文件和链接检查单列为静态结果。

此夹具只覆盖显式文件调用和独立会话持久化。原生发现须另开新会话测试不带显式路径的调用；调度、写入后中断恢复、并发修改及只撤本次差异的回退，须在调用方真实实现的隔离实例中有界测试。没有现有实现就记 NOT_RUN，不用另造模拟引擎证明能力。运行证据与私人部署配置不提交到此公开包。
